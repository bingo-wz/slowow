# 慢慢

面向小学班主任的 Android 原生工作台。当前正在开发，目标是减轻日常事项、班级记录和提醒带来的记忆负担。

Android 工程在 `android/`，Go 业务服务在 `server/`。测试版提供班级记录、本周菜单图片、通知、课程作息及提醒；MiMo 用于用户确认后的通知转待办及课程作息图片识别。当前测试包仅用于私下试用，目标手机的完整同步、提醒和换机恢复仍需进一步验证。

本周菜单只展示用户添加的菜单图片。课程与作息可手动维护，也可经确认后一次发送一至两张图片给 MiMo 识别，核对修改后再保存；不支持菜单识别或课程作息 PDF、Excel 导入。原有记录和图片继续保留。

教师课程时间表提供周视图、当日时间线、教师筛选、当前与下一项、分类统计和打印 / 保存 PDF。课程可补充类型、教师、班级、地点、角色、跨节结束位置及提醒；未分类的旧课程保留为“待确认”。学期首周日期需要自行填写才能计算周次；当前课程按周重复，暂不支持单双周或单次调课。

首页默认查看今天，横滑日历可以查看前后各七天，选中一天后可直接添加和编辑当天的待办。全部待办默认以月历收纳日程和历史记录，点选日期查看当天清单。记录页默认显示本周并选中今天，周历下方直接列出所选日期的请假和班级标记，也可切换周查看历史。已完成事项可折叠，完成时播放彩色礼花动效。正常同步在后台进行，不占用待办区域；同步需要处理时，设置图标显示小提示，详情可在设置中查看。全部待办按日期分组，默认按开始时间排序，同一日期、同一完成状态的事项都可以拖动，手动顺序优先。班级入口位于设置；班级标记记录支持编辑、删除以及分别复制两种状态的名单。

新建普通待办时，日期默认取自正在看的日历日期，也可改成今天、明天或其他日期；可选填第几节课。同一页可开启每周重复。重复事项可以只选星期，也可以为各星期分别设置开始和结束时间，相同时间段可一次应用到所有已选星期；重复从所选日期起生效。也可从“全部待办”右上角的循环图标管理固定安排。两个账号独立设置和完成。设置了完整开始和结束时间的待办，在结束后下次打开应用约一秒后自动完成：当天先展示勾选和礼花，再收入可折叠的已完成区；过往日期静默完成。自动完成后手动取消会保持未完成；只有重新调整时间段才会重新启用自动完成。时间段限同一天内，未设时间段的事项仍需手动完成。“午餐核销”可关联并查看对应日期的不在校用餐名单，课程表暂不自动生成待办。

“记录”中的请假支持选填原因。跨天请假可从其覆盖的任一天找到，编辑的是同一条记录。已撤销的请假可从开始日期查看和删除。不在校用餐名单按日期实时汇总固定校外用餐及全天或上午请假的学生，支持切换日期并复制；历史日期按当前设置和现有请假计算。设置中可单独调整应用字体大小，也可跟随系统。

“记录 → 课堂森林”支持教师手动设置动物头像、分组和互动方式，点亮后可按日、周、月查看覆盖情况。关照提醒可在本机开启，工作日为满七天未互动的关注学生提供提示。系统通知使用通用文字，学生信息只在登录后的课堂森林查看。地鼠乐园使用虚构角色，和班级名单独立。

构建前需在本机 `android/local.properties` 配置 `MANMAN_SYNC_BASE_URL` 和 `MANMAN_AUTH_BASE_URL`，或通过同名环境变量提供 HTTPS 地址。此文件不纳入版本管理；不要把密钥、真实学生资料和生产环境配置提交到仓库。

每次成功构建 Android 测试版，最新版都会自动保存到固定路径 `artifacts/慢慢-测试版.apk`；导出时会检查签名，避免不同签名覆盖已有安装包。使用 `adb install -r` 可覆盖安装并保留应用数据。

开发和测试应使用虚构学生及学校通知数据；正式使用真实信息前，先完成账号隔离、数据恢复、备份和学校授权相关检查。
