# 慢慢

面向小学班主任的 Android 原生工作台。当前正在开发，目标是减轻日常事项、班级记录和提醒带来的记忆负担。

Android 工程在 `android/`，Go 业务服务在 `server/`。测试版提供班级记录、本周菜单图片、通知、课程作息及提醒；MiMo 用于用户确认后的通知转待办及课程作息图片识别。当前测试包仅用于私下试用，目标手机的完整同步、提醒和换机恢复仍需进一步验证。

本周菜单只展示用户添加的菜单图片。课程与作息可手动维护，也可经确认后一次发送一至两张图片给 MiMo 识别，核对修改后再保存；不支持菜单识别或课程作息 PDF、Excel 导入。原有记录和图片继续保留。

教师课程时间表提供周视图、当日时间线、教师筛选、当前与下一项、分类统计和打印 / 保存 PDF。课程可补充类型、教师、班级、地点、角色、跨节结束位置及提醒；未分类的旧课程保留为“待确认”。学期首周日期需要自行填写才能计算周次；当前课程按周重复，暂不支持单双周或单次调课。

首页显示当天待办、菜单、学校通知及设置；全部待办按日期折叠，同一天内可拖动排序，完成后勾选划线。班级入口位于设置；班级标记记录按日期折叠，支持编辑、删除以及分别复制两种状态的名单。

“记录”中的请假按开始日期分组折叠，连续多天的请假保留为一条；已撤销的请假可以删除。不在校用餐名单按日期实时汇总固定校外用餐及全天或上午请假的学生，支持切换日期并复制；历史日期按当前设置和现有请假计算。设置中可单独调整应用字体大小，也可跟随系统。

构建前需在本机 `android/local.properties` 配置 `MANMAN_SYNC_BASE_URL` 和 `MANMAN_AUTH_BASE_URL`，或通过同名环境变量提供 HTTPS 地址。此文件不纳入版本管理；不要把密钥、真实学生资料和生产环境配置提交到仓库。

每次成功构建 Android 测试版，最新版都会自动保存到固定路径 `artifacts/慢慢-测试版.apk`；导出时会检查签名，避免不同签名覆盖已有安装包。使用 `adb install -r` 可覆盖安装并保留应用数据。

开发和测试应使用虚构学生及学校通知数据；正式使用真实信息前，先完成账号隔离、数据恢复、备份和学校授权相关检查。
