## CloudBase 需要的信息

1. OAuth 已由用户在浏览器中授权；后续优先通过官方连接器读取所选环境，不需要用户粘贴腾讯云账号密码、短信验证码或密钥。连接器申请了环境管理权限，可能包含读写操作；以授权页面展示的范围为准。
2. 已读取环境 ID、上海地域及体验版套餐；若它不是“慢慢”使用的环境，需要重新选择。
3. 手机号验证码登录已开启，平台返回默认短信通道就绪。后续应实际验证短信送达、登录、可用额度和费用；官方文档对默认短信通道与单独配置短信服务商的说明存在差异，以目标账号控制台和实际验证为准。若要求短信签名或模板，再按控制台指引申请。
4. 免费体验版当前有每月 3,000 资源点、每次续期 6 个月且不能自动续期，具体条件以[腾讯云价格说明](https://cloud.tencent.com/document/product/876/127357)及账号实际状态为准；不假设短信长期免费。

手机号、账号和登录会话由 CloudBase 认证服务处理；学生名单、请假、通知、菜谱和私有图片保存在现有服务器。Android 客户端使用 CloudBase 身份认证能力时，服务端仍必须独立验证登录凭证和用户归属。

## 服务器 SSH 需要的信息

1. 公网地址已由用户提供，使用 `ubuntu` 和默认 SSH 22 端口已成功登录；主机指纹已由用户通过腾讯云网页终端独立确认。
2. 专用 SSH 公钥已绑定，私钥留在本机。腾讯云说明绑定密钥后默认可能禁止 `root` 密码登录。[腾讯云操作说明](https://cloud.tencent.com/document/product/1207/44573)
3. 已验证 SSH 22 端口可以访问；进一步调整防火墙前应先检查现有规则，按实际网络范围授权。
4. 系统、内存和磁盘已检查；Docker 未安装。慢慢服务只监听本机，由 Caddy 提供 HTTPS，不重装系统。
5. 目前使用公网 IP 的 Let's Encrypt 短期证书及 Caddy 自动续期，用户已开放 TCP 80/443。加密备份及密钥管理见数据备份文档；真实短信和模型费用待验证。

## 不需要发送到聊天的信息

- 腾讯云账号密码、手机验证码、MFA 恢复码。
- 服务器密码或 SSH 私钥。
- 腾讯云 `SecretKey`、管理员 API Key、CloudBase 管理密钥或登录令牌。

优先使用浏览器 OAuth、SSH 公钥和受限的服务账号；若未来需要配置某个服务端凭证，使用腾讯云官方控制台或本机安全方式处理，避免放进聊天、代码仓库或 Android 安装包。

## 后续验证顺序

1. 已只读查看 CloudBase 已授权环境及登录配置，手机号验证码登录已开启；后续核对实际短信送达和费用，并在客户端联调注册登录流程。

3. 身份认证、数据库、服务和必要端口已配置；开发阶段使用测试账号和脱敏数据。
