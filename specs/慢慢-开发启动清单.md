# 慢慢：开发启动清单

更新时间：2026-11-07

## 当前结论

可以开始第一版开发。现有信息足以完成 Android 项目基础、CloudBase 登录接入、班级名单、请假与午餐核验的初步实现；周菜谱截图、通知截图、课程表和作息表可以后续提供，再用来完善识别和日程规则。

第一版先私下安装给一位老师试用，暂不以应用商店上架为前提。开发和测试阶段使用虚构学生姓名、模拟菜单和模拟通知。

## 已具备的条件

- 已确定 Android 原生开发、Kotlin、Jetpack Compose 和单色 Material 3 设计约束。
- 已有 CloudBase 体验环境并完成授权，手机号验证码登录已开启；实际发送短信和 App 端登录还需联调。
- 腾讯云轻量服务器已通过 SSH 公钥连接，主机身份已核验；账号认证由 CloudBase 托管，班级业务数据计划放在自己的服务器。
- 小米 12S 作为首要测试设备；班级 52 人，支持从 Excel 复制并粘贴姓名；部分学生长期在校外用餐。
- 午餐核验时间默认约 12:30，可修改；12:30 之后补录当天请假不自动扣除当天午餐人数，可手动调整。跨多天请假应逐日判断，离线同步延迟不改变登记时间。

## 开发环境准备

- 本机已有 JDK 21，系统默认 Java 仍为 JDK 8；已创建项目专用环境脚本，使 Android 构建进程使用 JDK 21，避免影响其他项目。
- 已安装 Android SDK、Gradle、`adb`、NDK 和 Android 16 ARM64 模拟器；独立的 Kotlin + Compose 验证工程已编译并在模拟器中成功启动，原生库去符号能力也已验证。Android Studio 不是命令行构建的前提；正式工程需配置 Gradle Wrapper。
- 当前工作区包含规划文档和环境脚本，尚无正式 Android 产品工程或 Git 仓库。建立项目时应设置合适的构建配置、忽略规则和依赖版本，并以实际生成的安装包测试体积。
- 真机联调时需要使用小米 12S，具体 Android / MIUI 或 HyperOS 版本及 USB 调试授权可届时确认。

## 可先开展的工作

1. 准备开发工具，创建 Android 项目、基础主题、主导航和运行方式。
2. 依照 CloudBase 官方 HTTP API 接入手机号验证码注册与登录，并用测试账号核对发送、验证、会话与退出；在实际测试前核实短信额度和费用。
3. 实现班级名单粘贴、学生视图、请假登记、长期校外用餐设置和午餐核验；用虚构数据验证跨天、补录和去重。
4. 建立数据持久化、账号隔离、云端服务和同步基础；正式录入学生数据前验证权限和备份恢复。
5. 实现课表、菜谱和通知的手动录入与展示入口；获取样例后再接入识别与日程提取、核对原文和提醒行为。

## 可以稍后提供或决定

- 脱敏的周菜单、学校通知、课程表和作息表样例；用于确定图片表格样式、识别效果和实际日程。
- 小米 12S 的 Android 与系统版本；用于真机兼容、提醒和性能验证。
- 识别服务的可选供应商、费用预算和数据保留政策；选择前先保留人工录入流程。
- 服务器域名、HTTPS 和备份位置；云端正式对外使用及真实数据迁入前需要确定，不阻塞本地界面和模拟数据开发。
- 班级标记常用事项、长期校外用餐名单的录入方式、截止后修改旧请假的规则，以及节假日 / 调休处理。
