# 慢慢：项目上下文

更新时间：2026-11-08

## 项目定位与已确认需求

“慢慢”是给小学二年级语文老师兼班主任使用的 Android 原生工作台，第一版由用户对象私下试用。目标手机是小米 12S，班级约 52 人，学生姓名从 Excel 复制粘贴，存在长期校外用餐的学生。

- 本周菜单只需查看图片；没有图片时手动添加，已有图片可以更换。首页不再显示当天菜品，也不进行菜单识别或每日菜品录入。
- 记录跨天请假。按照所选日期实时生成不在校用餐名单：包含固定不在校用餐及该日全天或上午请假的学生，下午请假不计入，重合去重；补录时间不影响计算。默认显示今天，可切换日期和复制名单。查看过去日期时也按当前学生设置及现有请假计算，不作为历史快照。
- 每次为班级事项自定义两种状态，保存全班可视化结果和姓名快照。
- 班级标记按日期分组折叠，可编辑和删除；两个状态分别复制对应的姓名文字，不提供图片或图表导出。
- 首页只展示当天待办，全部待办按日期分组并可折叠；同一天内支持拖动排序，完成项可勾选并划线，排序通过现有账号同步。
- 独立维护作息节次与每周课程，课程、待办可设置提醒；通知支持文字及图片导入或系统分享，待办保留原通知关联。
- 课程和作息只手动添加；课程表、作息表的图片、PDF、Excel 导入与识别均已取消。通知每次发送给联网 AI 前必须由老师确认；识别候选必须人工核对后保存。
- Android 使用单一主色和中性色，关闭动态取色；8dp 网格、最多四级字号和两种字重、两至三档圆角，界面层级靠背景色差。动效仅用于状态变化，200–300ms，使用 Material 3 MotionScheme。

## 当前实现

- 工程位于 `android/`，使用 Kotlin、Jetpack Compose、Room、WorkManager 和 Material 3。JDK 21、Android SDK、Gradle Wrapper 和 Android 16 ARM64 模拟器已准备；构建输出放在 `~/Library/Caches/manman-build`，避免同步目录产生重复构建文件。
- 最新 Android 测试包固定为 `artifacts/慢慢-测试版.apk`；每次成功执行 `:app:assembleDebug` 都自动更新此文件。开发中的未完成构建应设置 `MANMAN_SKIP_APK_EXPORT=1`，验证通过后正常构建再交付。后续交付始终使用这个路径，保留与旧包一致的签名以支持覆盖安装。
- 已实现手机号短信登录客户端、本地凭证保护、离线记录与账号隔离同步；学生、请假、实时不在校用餐名单、双状态标记、周菜单图片、手动课程作息、通知与待办均有操作入口。已实现系统分享文字/图片、原图查看及课程/待办提醒。
- 用户已完成真实手机号登录，并确认对象手机的待同步数量已归零；云端已有一个账号的 52 名学生及一条午餐调整。换机恢复、小米系统提醒和启动速度仍需验证。
- MiMo 密钥已由用户安全配置；虚构文字加图片的模型调用已成功。识别额度最多绑定两个账号，班级数据仍按账号隔离；真实通知的识别准确度仍需脱敏样例验证。CloudBase 环境没有 Token Credits 资源包，本方案使用用户提供的 MiMo 密钥，不购买该资源包。
- 应用字号默认跟随系统，也可在设置中单独选择偏小、标准、偏大、大或特大，不改变手机系统设置；大字体采用重排和滚动，班级标记网格按实际可用宽度及字号调整列数。
- 首页以今日待办为主体，顶部显示日期、本周菜单的像素嫩芽、学校通知及设置；班级和课程作息从设置进入。请假选学生使用 Android 自带 ICU 拼音分组与字母跳转，姓名有多音字时可在学生信息中手动指定首字母。桌面图标使用参考图生成的像素羊羊。应用字体支持系统、楷体、可爱和手写：开源字库首次选择时从用户服务器下载，校验后保存在本机，不计入 APK，原始许可包含在应用中。
- 待办列表使用 Apache-2.0 的 Reorderable 组件；日期、原通知和提醒保留原有语义，旧待办缺少排序字段时可正常读取。重排写入本地队列，按账号同步。
- 菜单和课程作息识别、课程作息文件导入及相关解析代码已移除。旧版每日菜单、按星期生效的节次、周菜单图片及旧午餐核验和手动调整记录继续保留并可正常同步，不做数据删除；旧午餐记录不参与新名单计算。
- 目标 GitHub 仓库为公开仓库。业务地址通过本机 `android/local.properties` 提供；凭据、真实学校文件、本地数据库和安装包不得提交。
- 2026-11-08 用户调整范围：不再开发菜单、课程表或作息表识别；通知识别及其不含正文或身份信息的诊断保留。
- Material 3 暂用 `1.5.0-rc01` 以使用公开 MotionScheme，正式发布前应重新检查稳定版与兼容性。

## 云服务和数据保护

- CloudBase 上海环境用于手机号身份认证；环境体验版显示 2027-05-07 到期，未开自动续期。真实短信登录已通过，短信额度和费用仍需留意。具体环境和服务地址保存在本机未纳入版本管理的构建配置中。
- 用户现有腾讯云轻量服务器 2 核 2 GB、Ubuntu 24.04，业务服务为 Go + PostgreSQL 16，服务端通过 CloudBase 校验用户身份，数据库对每个账号启用强制行级隔离。附件保存在服务账号私有目录，按账号隔离，每张最多 8 MB、每账号暂限 512 MB。
- 用户已在轻量服务器防火墙允许 TCP 80/443，Caddy 提供 HTTPS，业务服务仅监听本机。当前使用 Let's Encrypt 公网 IP 短期证书及自动续期，必须保持 Caddy 和 80/443 可用，不能把一次签发视为长期有效。
- Caddy 的 `/fonts/` 仅公开提供 `/srv/manman-fonts` 中的三份开源字库及许可，目录由 root 持有；学生数据和私有附件不在此目录。客户端按固定 SHA-256 校验字体并支持缓存后离线使用。
- `tools/backup-server.sh` 可把数据库快照和私有附件加密备份到本机；已在独立测试库验证恢复。当前仅有手动备份，恢复密钥位于本机并须另行安全保管，不能依赖服务器和同一台电脑作为唯一副本。
- 服务器使用本机 SSH 别名 `manman-server` 及独立核验过的主机公钥。不要在聊天或代码中写入 SSH 私钥、验证码或访问令牌。
